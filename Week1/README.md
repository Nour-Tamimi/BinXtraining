# Week 1 — Python & Data Science Foundations

## Overview
Week 1 covered setting up a reproducible Python environment and building
fluency in the core data-science stack: NumPy, Pandas, and Matplotlib, all
within the Jupyter Notebook workflow.

## What I Learned

- **Environment setup** — created a virtual environment, installed core
  libraries, and froze dependencies to `requirements.txt` for reproducibility.
- **Python fundamentals** — data types, control flow, functions, list
  comprehensions, and basic OOP as the building blocks for clean data code.
- **NumPy** — creating arrays, indexing/slicing, boolean masking, and
  vectorized operations instead of slow Python loops.
- **Pandas** — loading and inspecting DataFrames, filtering rows, cleaning
  missing values/duplicates, and aggregating data with `groupby`.
- **Matplotlib** — building labeled line, scatter, bar, and histogram plots,
  and combining them into subplots for comparison.

## Hands-On Work

1. Set up the environment and confirmed installed library versions.
2. Practiced core Python syntax through small functions and a basic class.
3. Manipulated NumPy arrays: slicing, masking, and broadcasting.
4. Loaded and cleaned a real dataset in Pandas, then aggregated it by group.
5. Built an integrated mini-notebook combining NumPy, Pandas, and Matplotlib
   into a full load → process → visualize pipeline.
6. Committed all notebooks and requirements.txt to GitHub.

## Key Takeaway
NumPy, Pandas, and Matplotlib form the foundation every later ML workflow
builds on. This week's load → clean → explore → visualize pattern repeats
throughout the rest of the program.
